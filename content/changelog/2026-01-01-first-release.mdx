Each changelog entry is a file in `content/changelog`. Name files with the date first so they
sort naturally, for example `2026-03-14-dark-mode.mdx`.

- `type` accepts `added`, `improved`, `fixed`, `removed` and `security`.
- Entries get anchor links, so you can share a link to a single release.
