Welcome to the documentation. Every page is a Markdown (MDX) file in `content/docs`, so writing
docs is as simple as adding a file.

## How pages map to URLs

| File                                    | URL                          |
| --------------------------------------- | ---------------------------- |
| `content/docs/index.mdx`                | `/docs`                      |
| `content/docs/guides/writing-pages.mdx` | `/docs/guides/writing-pages` |

## Searching

Press <kbd>⌘</kbd> <kbd>K</kbd> (or <kbd>Ctrl</kbd> <kbd>K</kbd>) anywhere in the docs to search. The search index is
built when the site is built and downloaded only when you first open search.
