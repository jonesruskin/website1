React, Next.js and other frameworks

Load the script once, call baton.pass() when the job is done. Recipes for React, Next.js, Vue, Svelte and plain HTML.

The recipe is the same everywhere: load the script once, then call window.baton?.pass() when your tool succeeds. Frameworks only change where those two lines live.

Strict Mode

In development, React runs effects twice. That can request two cards. It doesn't happen in production, but if it bothers you, guard the call with a ref.

Testing

  • In tests, don't load the script. window.baton?.pass() is a no-op when baton is missing.
  • Use your real site key in staging to see real cards. Impressions and clicks from staging count like any others, so use a separate tool entry if you don't want them mixed with production.
